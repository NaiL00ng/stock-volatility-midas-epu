## 当前入口和输入版本

当前论文的点预测入口是[run_dec_revision.py](../scripts/run_dec_revision.py)，区间入口是[run_revised_intervals.py](../scripts/run_revised_intervals.py)，结果位于[results/revised](../results/revised/README.md)。安装与完整命令见[运行说明](../docs/reproduction.md)。`run_experiments.py`及其默认目录用于历史候选训练，不生成当前论文版本。

具有相应使用权限时，将下列五个文件放入本目录；文件名和训练参数由[experiments.json](../configs/experiments.json)读取。行情读取首个工作表，EPU显式读取`Monthly`。

| 输入 | 文件名 | 当前存档的读取工作表 |
| --- | --- | --- |
| CSI300行情 | `CSI300_daily_20100104_20260331.xlsx` | 首表`data` |
| 上证50行情 | `SSE50_daily_20100104_20260331.xlsx` | 首表`data` |
| 纳斯达克综合指数行情 | `NASDAQZH_daily_20100101_20260331.xlsx` | 首表`Sheet1` |
| 中国月度EPU | `epu_newVersion_2000-2026.xlsx` | `Monthly` |
| 美国月度EPU | `US_Policy_Uncertainty_Data.xlsx` | `Monthly` |

| 字段 | 含义与要求 |
| --- | --- |
| 行情`date` | 日期，可解析、无重复，按时间升序；需要真实交易日校验 |
| `open`、`high`、`low`、`close` | 正数价格；`high`不低于开收盘、`low`不高于开收盘 |
| `volume` | 数值成交量；零值会使对数成交量缺失，必须核对原因，不能一概当作休市删除 |
| EPU`observation_date` | 月度标签，每月一条且连续；缺月时基于行的shift不等于日历月滞后 |
| EPU`CHNMAINLANDEPU` | 正数指数；美国文件沿用这个字段名，但数值表示美国EPU |

当前函数会排序并对行情日期去重、在特征构造后删除含缺失的行；这些操作不替代输入质量审查。新数据应先检查重复、缺月、非正数和交易日历，不应把静默删除后的结果当作已验证输入。

中国EPU使用论文引用的Davis、Liu、Sheng指标。两个中国行情工作簿的metadata记录了`stock_zh_index_hist_csindex`接口；这不代替上游真实性审计。美国EPU的上游下载版本仍未完整保存。[输入SHA256](../results/verification/input_fingerprints.csv)用于识别已核对文件，不表示授予数据许可，也不证明真实时点可得性。

## 当前论文采用的样本

机器可读的口径基准是[sample-splits.json](../configs/sample-splits.json)，依据本地修订预测面板核对。这里的数量只适用于已记录输入，不要求其他数据集恰好具有相同行数。

| 当前正文市场 | 特征及目标完整的建模行 | 初始训练 | 验证 | 测试 | 测试预测起点日期 |
| --- | ---: | ---: | ---: | ---: | --- |
| CSI300 | 3919 | 1500 | 500 | 1919 | 2018-05-03至2026-03-30 |
| 上证50：日历修正输入 | 3919 | 1500 | 500 | 1919 | 2018-05-03至2026-03-30 |
| 纳斯达克 | 4054 | 2000 | 500 | 1554 | 2020-01-23至2026-03-30 |

样本按保留行的时间顺序切分，不打乱。上述日期是预测起点`t`，不是被预测收益率的日期。目标为`log(r[t+1]^2 + 1e-8)`，`r`是未乘100的对数收益率；代码先按输入的下一行形成目标，再处理特征缺失。因此“下一行”是否等于“下一交易日”必须依据输入日历判断。月度EPU先取对数，`epu_lag1`为前一月值，最多24个月；这仍不等于已经按真实发布日期和历史修订版本对齐。

XGBoost从验证段起生成扩展窗口样本外预测，每20个保留行重估。第二阶段的500条验证行中首条滞后残差不可用，留下499条，分299条拟合、200条选规格；它们不是额外测试样本。DEC和无EPU的XGB-AR在测试段每60行重估。[稳定求解规则](../configs/dec-revision.json)与共享配置共同定义当前方法。

CSI300区间比较采用五模型、两种名义水平、三个校准窗口，共30组；统一1859个预测起点日期，2018-07-27至2026-03-30。该口径不同于点预测的1919条。描述统计则用3942个价格观测形成的3941条收益率；它也不同于3919条模型样本。

## 历史口径为何不同

上证50历史输入含2018-06-18的已确认休市行。原处理顺序使其污染前一行目标，相关零成交量还影响后续特征。当前入口在特征与目标构造**之前**排除此行，重建3919条模型样本并比较五模型；原工作簿不变。旧样本为3915条，切分1500/500/1915，仅作为历史控制保存。不能因删除一条输入却增加最终完整行就推断计数错误；滚动和滞后缺失的影响必须一并考虑。

历史描述统计多出的零值已定位到2018-06-15与2018-06-19收益率之间，正确论文使用3941条口径；用于识别旧统计指纹的人工零值未进入模型。全部历史说明见[来源追查](../docs/provenance-resolution.md)和[版本对应](../docs/version-map.md)。现有日历修正不是所有市场、所有日期的完整上游审计。
