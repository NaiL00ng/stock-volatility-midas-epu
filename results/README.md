# 结果目录说明

当前论文使用[revised/](revised/README.md)。下面各原目录保留历史证据，数值不被新结果静默替换；修订版新增XGB-AR，纳斯达克改选指数Almon，上证50正文采用日历修正数据。

| 子目录 | 内容 | 使用限制 |
| --- | --- | --- |
| `csi300/` | 主实验汇总、检验、规格搜索、权重及图件 | 由存档预测复算一致；候选已重训；XGBoost已通过兼容构建逐点重现；DEC仍有差异 |
| `sse50/` | 上证50同类结果 | 历史训练1500、验证500、测试1915；含已确认休市日产生的人工目标，修正重估对照另存 |
| `nasdaq/` | 纳斯达克同类结果 | 训练2000、验证500、测试1554；最优权重Beta |
| `intervals/` | 24组区间设置的汇总、覆盖检验及主设置图 | 历史表各模型有效日期不完全一致；`coverage_valid`仅为旧版启发式阈值标记 |
| `descriptive/` | 历史描述统计、检验及图 | 含额外零值指纹，仅用于历史追溯；论文已改用下列修正目录 |
| `descriptive-corrected/` | 当前3941条有效收益率的统计、检验及图件 | 正确口径；不包含人为插入的零值 |
| `verification/` | 算术核对、来源追查、输入匹配、重训差异及共同日期比较 | 分清检查类型；不证明历史预测实时可得 |

原21个CSV及19张图件的数值/像素保留，不静默重写历史结果。图件中的区间排名指各自有效样本；严谨跨模型比较请看[共同日期结果](verification/interval_common_dates.csv)。

`calculation_checks.csv` 的 `passed` 是数值容差核对，非科学结论或理论适用性判定。保留其与历史表的5项差异；这些差异已由新增来源追查解释，正确统计另存。详见[追查记录](../docs/provenance-resolution.md)。

[区间构造核对](verification/interval_construction_checks.csv)记录从逐期点预测重建的24组上下界比较：全部匹配。它验证已保存预测与区间之间的计算关系，不验证历史训练来源。
